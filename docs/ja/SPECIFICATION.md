# アプリ機能仕様書 (SPECIFICATION)

QuMaEditor (Quick & Minimal Markdown Editor) の機能仕様およびアーキテクチャ概要です。

---

## 1. 概要 (Overview)
QuMaEditor は、Tauri v2 + Rust バックエンドおよび React + TypeScript フロントエンドで構築された、超軽量・超高速なディスクトップ Markdown エディタです。(現在のバージョン: v1.1.0)

---

## 2. コア機能仕様 (Core Specifications)

### 2.1 エディタ & プレビュー (Editor & Preview)
- **リアルタイム GFM ライブプレビュー**: GFM (GitHub Flavored Markdown) 仕様、表組みアライメント (左寄せ `:---`, 中央 `:---:`, 右寄せ `---:`), タスクリスト, 絵文字, コードブロック構文ハイライト (`vscDarkPlus` / `prism`) に完全対応。
- **YAML Front Matter 保護領域**: タイトル, 作成日時, 文字コードは自動保護。タグ (`doc.tags`) のみ直感的に追加・削除編集可能。
- **ハイコントラストカラーモード**: ライトモードおよびダークモードに全UI（各種モーダル、スクロールバー、コードハイライト）が完全連動。

### 2.2 爆速全文検索 & タグ検索 (Fast Search & Tag Search)
- **キーワードハイライト表示**: 入力検索キーワードに一致するタイトル・本文・検索行テキストを鮮やかな `<mark>` イエローバッジで強調。
- **タグ絞り込み検索**: タイトル・本文に加え、Front Matter のタグ (`#ガイド` 等) でもドキュメントを即座に絞り込み。
- **Rust 転置インデックス検索**: 大容量ドキュメント群の単語インデックス化によるネイティブ高速検索。

### 2.3 印刷 & PDF エクスポート (Print & Direct PDF Export)
- **ダイレクト PDF エクスポート**: 印刷ダイアログを起動することなく、プレビュー画面のレイアウトスタイルそのままにワンクリックで `.pdf` ファイルを直接生成・保存。
- **A4 フルサイズ印刷 (`Ctrl + P`)**: 印刷時、編集画面 (`Editor.tsx`) および全 UI パーツを `print:hidden` で完全に除外。プレビュー表示領域のみを用紙の左端から右端まで横幅 100% で美しく印刷。

### 2.4 Rust ネイティブアクセラレーション (Rust Native Acceleration)
- **大容量ファイルチャンクストリーミング**: 10MB 超えテキストの段階的ストリーミング読み込み。
- **マルチスレッドエンコーディング一括変換**: `rayon` を使用した複数ファイルの UTF-8 / Shift_JIS 高速一括変換。
- **テキスト Diff 比較演算**: `similar` クレートによる高速な行単位差分抽出演算。

## 3. システム動作環境
- **バージョン**: v1.1.0
- **OS**: Windows 10 / 11 (Tauri v2 Native Window)
- **ランタイム**: Rust Native Engine + WebKit / WebView2
