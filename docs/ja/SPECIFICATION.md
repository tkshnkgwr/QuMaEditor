# アプリ機能仕様書 (SPECIFICATION)

QuMaEditor (Quick & Minimal Markdown Editor) の機能仕様およびアーキテクチャ概要です。

---

## 1. 概要 (Overview)
QuMaEditor は、Tauri v2 + Rust バックエンドおよび React + TypeScript フロントエンドで構築された、超軽量・超高速なデスクトップ Markdown エディタです。(現在のバージョン: v1.2.2)

---

## 2. コア機能仕様 (Core Specifications)

### 2.1 エディタ & プレビュー (Editor & Preview)
- **起動時デフォルト表示モード**: アプリ起動時は「編集のみ (`editor`)」画面で開き、必要に応じてツールバーから分割表示 (`split`) やプレビュー (`preview`) へ即座に切り替え可能。
- **選択範囲へのフォーマット適用 ＆ カーソル自動復元**: ツールバーの太字 (`**`)・斜体 (`*`)・下線 (`<u>`)・打ち消し線 (`~~`) ボタンは、テキスト選択範囲があればその選択文字列をラッピング適用し、非選択時はカーソル位置へ挿入。処理後はカーソル位置とフォーカスを自動で復元。
- **見出し (H1~H3) のカーソル行行頭挿入**: 見出しボタンを押すと、テキスト末尾ではなく現在のカーソル行の行頭に `# ` / `## ` / `### ` マーカーをスマート挿入・置換。
- **プレビュー画面の Ctrl + スクロールホイールズーム**: プレビュー領域で `Ctrl + スクロールホイール`（またはトラックパッド）により表示倍率を 50% 〜 300% の範囲で自在に拡大縮小可能。1.0倍以外のときは右上にワンクリックリセットバッジを表示。
- **リアルタイム GFM ライブプレビュー**: GFM (GitHub Flavored Markdown) 仕様、表組みアライメント (左寄せ `:---`, 中央 `:---:`, 右寄せ `---:`), タスクリスト, 絵文字, コードブロック構文ハイライト (`vscDarkPlus` / `prism`) に完全対応。
- **YAML Front Matter 保護領域**: タイトル, 作成日時, 文字コードは自動保護。タグ (`doc.tags`) のみ直感的に追加・削除編集可能。
- **ハイコントラストカラーモード**: ライトモードおよびダークモードに全UI（各種モーダル、スクロールバー、コードハイライト）が完全連動。

### 2.2 爆速全文検索 & タグ検索 (Fast Search & Tag Search)
- **キーワードハイライト表示**: 入力検索キーワードに一致するタイトル・本文・検索行テキストを鮮やかな `<mark>` イエローバッジで強調。
- **タグ絞り込み検索**: タイトル・本文に加え、Front Matter のタグ (`#ガイド` 等) でもドキュメントを即座に絞り込み。
- **Rust 転置インデックス検索**: 大容量ドキュメント群の単語インデックス化によるネイティブ高速検索。

### 2.3 印刷 & PDF エクスポート (Print & Direct PDF Export)
- **ダイレクト PDF エクスポート**: 印刷ダイアログを起動することなく、プレビュー画面のレイアウトスタイルそのままにワンクリックで `.pdf` ファイルを直接生成・保存。
- **A4 フルサイズ印刷 (`Ctrl + P`)**: 印刷時、編集画面 (`Editor.tsx`) および全 UI パーツを `print:hidden` で完全に除外。プレビュー表示領域のみを用紙の左端から右端まで横幅 100% で美しく印刷。

### 2.4 ファイル保存 & 二重保護アーキテクチャ (File Save & Dual Protection Architecture)
- **実ファイル直上書き保存 (`Ctrl + S`) ＆ 名前を付けて保存 (`Ctrl + Shift + S`)**: Tauri ネイティブ直書き込み (`write_file_native`) を統合。ローカル PC 上の実際の `.md` ファイルパス (`filePath`) を保持し、手動保存および打鍵後の自動保存タイマーで PC 上の実ファイルへエラーなく即座に上書き更新 (`💾 実ファイルに保存`)。
- **対象フォルダをエクスプローラーで開く**: PC 上の実ファイル (`filePath` が存在) である場合、タイトルバーの「ファイル」メニューからその親フォルダを Windows エクスプローラーで直接開くネイティブ機能 (`open_folder_native`) を搭載。
- **クラッシュ消失防止・二重保護機能 (LocalStorage セーフティ)**: 万が一の PC 突然停止やアプリ異常終了（クラッシュ）に備え、入力・編集中の最新データは常時 LocalStorage へバックグラウンド保護保存 (`📦 アプリ内(LocalStorage)に保存`)。未保存ノートや新規ドキュメントであっても次回起動時に 100% 確実に直前の状態へ復元。バージョン情報画面 (`AboutModal`) でその仕組みを図解・比較説明。
- **保存ステータスの可視化バッジ**: ユーザーが「今どこに保存されているか」を一目で識別できるよう、タイトルバーおよびステータスバーに `💾 実ファイルに保存 (時刻)` と `📦 アプリ内(LocalStorage)に保存 (時刻)` を明確に使い分けてリアルタイム表示。
- **二重起動防止 (Single Instance)**: 既に起動している場合は二重起動をブロックし、既存の QuMaEditor ウィンドウを前面化。受け取ったファイルパスを自動的に新タブでオープン。
- **Windows エクスプローラー右クリック連携**: アプリ起動時およびインストール時に「QuMaEditorで開く」をエクスプローラーのコンテキストメニューに自動登録。
- **内部ストレージ (AppData / LocalStorage) の可視化 & キャッシュ整理**: 設定画面 (`SettingsModal`) で AppData ディレクトリパスの表示・コピー、リアルタイム使用量 (KB/件数) の表示、不要な一時キャッシュのワンクリック整理に対応。「完全初期化」ボタンは誤操作防止のためフッター最下部左端に独立配置。

### 2.5 Rust ネイティブアクセラレーション (Rust Native Acceleration)
- **大容量ファイルチャンクストリーミング**: 10MB 超えテキストの段階的ストリーミング読み込み。
- **マルチスレッドエンコーディング一括変換**: `rayon` を使用した複数ファイルの UTF-8 / Shift_JIS 高速一括変換。
- **テキスト Diff 比較演算**: `similar` クレートによる高速な行単位差分抽出演算。
- **ネイティブフォルダ起動**: Windows `explorer.exe` を安全に呼び出す `open_folder_native` コマンド。
