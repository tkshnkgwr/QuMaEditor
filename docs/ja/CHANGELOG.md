# 更新履歴 (CHANGELOG)

QuMaEditor の主要な変更点およびリリース履歴です。

## [1.4.5] - 2026-09-14

### 💎 Markdown プレビューの Obsidian 完全互換化 (v1.4.5)

- **Enter 1回での自動改行対応 (`Preview / LineBreak`)**:
  - 行末スペース2個不要で Enter 1回（単一改行）で `<br />` 改行を生成する Obsidian 互換の改行仕様を実装。連続空行による段落分けは維持。
- **Obsidian コールアウト記法の完全カードレンダリング (`Preview / Callout`)**:
  - `> [!NOTE] タイトル`, `> [!WARNING]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!CAUTION]`, `> [!TODO]`, `> [!SUCCESS]`, `> [!BUG]` 等の主要コールアウト記法に対応。
  - 左境界線アクセントカラー（4px）、タイトル・アイコン・角丸背景カードのスタイルを適用し、ライト／ダーク／印刷（PDF 出力）の全テーマで最適化。
- **蛍光ペンハイライト記法 (`Preview / Highlight`)**:
  - `==重要なテキスト==` を `<mark class="obsidian-highlight">` に自動変換し、Obsidian 準拠の半透明イエロー背景＆丸角パディングを適用。
- **内部 Wiki リンク記法 (`Preview / Wikilink`)**:
  - `[[ノート名]]` および `[[ノート名|別名エイリアス]]` を `<a class="internal-link">` に自動変換し、Obsidian 固有のパープルカラー・下線スタイルを適用。
- **箇条書き・リスト表示の完全復元 (`Preview / Typography`)**:
  - Tailwind CSS v4 の Preflight リセットで消えていた箇条書きマーカー（`disc`, `circle`, `square`, `decimal` 等）とインデント幅を完全復元。

## [1.4.4] - 2026-09-14

### ⚡ 大規模編集基盤刷新・Rust ネイティブ13大機能統合 ＆ 高速並列化 (v1.4.4)

- **大容量編集用 Rope データ構造の導入 (`Rope / Editor`)**:
  - `ropey` クレートによる B ツリー Rope バッファ管理（`rope_buffer.rs`）を実装。
  - 数十万行・数十MB を超える超巨大テキストでも、メモリ再確保や文字列コピーのオーバーヘッドなく、行単位の高速な文字挿入・削除・スライス取得を実現。
- **メモリマップドファイル (mmap) による超巨大ファイルのゼロコピー瞬時オープン (`mmap / File I/O`)**:
  - `memmap2` クレートを活用したゼロコピーファイル読み出し（`mmap_reader.rs`）を実装。
  - OS 仮想メモリ空間へファイルを直接マッピングし、GB 級のファイルであってもメモリを圧迫することなく瞬時にオープン・部分チャンク読み出しが可能。
- **アトミックファイル書き込み ＆ mtime 完全保証 (`File I/O / Atomic`)**:
  - 一時ファイルへの完全書き込み＋ファイル置換（アトミックリネーム）による堅牢な保存機構を実装。
  - 停電やアプリ強制終了時でも元ファイルの破損リスクを完全に排除し、ファイル更新日時（mtime）の完全同期を保証。
- **実ファイル・LocalStorage 双方向同期の Rust 統合管理 (`SyncManager`)**:
  - ディスク上の実ファイルとアプリ内部 LocalStorage の同期状態を一元管理する `FileSyncManager`（`sync_manager.rs`）を実装。
  - アプリ自身の保存操作フラグ（保存ロック）と外部からの更新を厳密に分離し、保存直後の不要な「別プロセス更新検知」誤作動を根絶。
- **外部ファイル変更監視の Rust ネイティブ化 (`FileWatcher / notify`)**:
  - `notify` クレートを用いた OS カーネル直結のファイル変更監視（`file_watcher.rs`）を導入。
  - 外部エディタによる編集・保存・リネーム・削除イベントをバックグラウンドで高精度かつ低負荷に検知。
- **ワークスペース並列ファイルツリー走査 (`Workspace / ignore`)**:
  - `ignore` クレートを用いた高速並列ディレクトリスキャナー（`workspace_scanner.rs`）を実装。
  - `.gitignore` や `.git`, `node_modules`, `target` 等の除外パターンを尊重しながら、マルチスレッドでフォルダツリーを瞬時に構築。
- **ワークスペース横断の高速並列全文検索 (`Search / rayon`)**:
  - `rayon` 並列イテレータを用いたワークスペース全走査コマンド（`search_workspace_dir_native`）を実装。
  - フォルダ内に存在する多数の Markdown ドキュメントから、複数スレッドで一括並列キーワード検索を実行。
- **ドキュメント詳細差分比較の Rust ネイティブ化 (`Diff / similar`)**:
  - `similar` クレートによる詳細テキスト差分エンジン（`compute_detailed_diff_native`）を実装。
  - 行単位の差分（Old/New 行番号付き）に加え、同一行内の単語単位インライン変更（`inline_changes`）を高精度に算出。
- **複数ノート一括エクスポート ＆ ZIP 圧縮 (`Export / zip`)**:
  - `zip` クレートによる Deflate 圧縮アーカイブ出力（`export_zip.rs`）を実装。
  - ワークスペース内の複数ノートや画像アセットを、ディレクトリ構造を保持したまま単一の ZIP ファイルへ高速一括エクスポート。
- **日本語校正 ＆ Markdown 構文 lint の非同期解析 (`Proofreading / Lint`)**:
  - 日本語の文章校正および構文 lint 解析エンジン（`proofreading.rs`）を実装。
  - 連続する重複助詞（「のの」「はは」等）の検知、表記ゆれ（「サーバ」と「サーバー」等）の抽出、未閉じコードブロック（```` ``` ````）の自動検出を非同期で実行。
- **Mermaid 構文検証 ＆ SVG 差分ハッシュキャッシュ (`Mermaid / Cache`)**:
  - フロントエンドでの描画前に Mermaid 構文の正当性を Rust 側で事前検証する `mermaid_validator.rs` を実装。
  - ダイアグラムコードの SHA-256 ハッシュをキーとした差分キャッシュ機構により、同一ダイアグラムの不要な再レンダリングコストを完全排除。
- **Markdown プレビューの完全 Rust 化 ＆ シンタックスハイライト事前生成 (`Markdown / syntect`)**:
  - `pulldown-cmark` による HTML 生成と `syntect` による高速コードブロック構文ハイライト事前生成（`html_renderer.rs`）を実装。
  - ブラウザ側の重い JavaScript ハイライト処理をバックエンドへオフロード。
- **タイプライター・スクロール機能の実装 (`Editor / UI`)**:
  - エディタの入力カーソル行を画面中央付近に自動保持するタイプライタースクロール機能を導入。
  - 視線の上下移動を抑え、長文執筆に集中できる快適なライティング体験を提供。

### 🚀 Rust ネイティブ Markdown 自動整形・ゼロレイテンシ・CSV 高速化・モジュール分割 (v1.4.0)

- **Markdown 高速自動整形機能 (`Ctrl + Shift + F`)**:
  - Rust ネイティブエンジンにより、表組みの垂直整列、見出し前後の空行自動挿入、過剰連続空行の圧縮（コードブロック内は完全保護）を一瞬で実行する「✨ 整形」ボタン＆ショートカットを実装。
- **エディタ打鍵時のゼロレイテンシ化**:
  - 「編集のみ」モード時のプレビュー完全アンマウント・バイパス、および「分割表示」モード時のプレビュー解析遅延（Debounce / `useDeferredValue`）により、打鍵遅延ゼロの快適なタイピングを実現。
- **`Ctrl + E` カーソル位置・フォーカス自動復元**:
  - プレビュー表示から `Ctrl + E` またはヘッダー操作でエディタへ戻った際、直前のカーソル位置・行選択を自動復元しエディタへ即座にフォーカス。
- **Markdown プレビューでの Mermaid ダイアグラム リアルタイム描画＆ズーム**:

- **大容量 CSV ゼロコピー高速解析＆インタラクティブテーブル**:
  - 数万行の CSV も Rust ネイティブで高速パースし、型自動判別（文字型は左寄せ、日付は中央、数値型は右寄せ）＆クリックソート・検索フィルター付きプレビューテーブルを描画。
- **ドキュメント詳細統計ダッシュボードモーダル (`StatsModal`)**:
  - 文字数、単語数、行数、読了予想時間（分）、見出し数、リンク数をリアルタイム集計・グラフ表示するモーダルを新設（StatusBar クリックで呼び出し可能）。
- **外部プロセス更新検知＆選択時自動最新化・手動再読込 (`F5`)**:
  - 外部エディタでのファイル変更を `mtime` で自動検知しトースト通知・自動更新。手動でのディスク再読込 (`F5` / `Ctrl + R`) を実装。
- **保存ステータス表示の StatusBar 集約**:
  - TitleBar の保存状態表示を StatusBar（フッター）へ移動・集約し、UIをすっきり整理。

  - 基本フォントサイズに加え、「行間 (Line Height)」「エディタフォントファミリー (Monospace / Sans-serif)」「タブ幅」の設定項目を追加。
- **1,000行超過防止モジュール分割リファクタリング**:
  - バックエンド `text_processing/`（`stats.rs`, `yaml.rs`, `structure.rs`, `csv.rs`, `formatter.rs`, `html_renderer.rs`）へ分割。
