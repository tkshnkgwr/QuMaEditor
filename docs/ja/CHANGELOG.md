# 更新履歴 (CHANGELOG)

QuMaEditor の主要な変更点およびリリース履歴です。

---

## [1.0.0] - 2026-08-04

### 🚀 正式リリース (Initial Formal Release v1.0.0)

#### 🌟 コア機能 & Rust アクセラレーション
- **Tauri v2 + Rust Native 高速アーキテクチャ**: 低メモリ消費 (RAM ~35MB) と超軽量レスポンスを実現。
- **10MB+ 大容量ファイルストリーミング**: `read_file_chunk_native` によるメモリ溢れのない高速段階読み込み。
- **転置インデックス全文検索**: `LazyLock` を用いた Rust ネイティブ単語インデックス高速検索。
- **一括マルチスレッド文字コード変換**: `rayon` スレッドプールによる複数ファイル並列 UTF-8 変換。
- **高速テキスト Diff 比較演算**: `similar` クレートによる高速な行単位差分抽出。
- **文字コード自動判定 & 保存**: `encoding_rs` を用いた UTF-8 / Shift_JIS / EUC-JP 自動判定および CRLF/LF 改行保存。

#### 🔍 高度な検索 & ハイライト
- **キーワードハイライト検索**: 入力検索単語に一致する箇所を鮮やかな黄色バッジ (`<mark>`) で爆速強調表示。
- **YAML Front Matter タグ検索**: タイトル・本文に加え、Front Matter 内のタグ (`#ガイド` 等) での検索絞り込みに対応。
- **検索ヒット対象ファイル名の高コントラスト表示**: 対象ファイル名 (`hit.doc_title`) を太字の高コントラストカラー (`text-cyan-300` / `text-cyan-900`) でクッキリ表示。

#### 📄 プレビュー・印刷・ダイレクト PDF
- **ワンクリック・ダイレクト PDF ファイル保存**: 印刷ダイアログを起動せず、プレビュー描画スタイリングそのままにワンクリックで `.pdf` ファイルを直接生成・保存。
- **A4 フルサイズ印刷対応 (`Ctrl + P`)**: 印刷ダイアログ出力時、編集画面 (`Editor.tsx`) および全 UI パーツを `print:hidden` で完全に排除し、プレビュー文章のみを A4 100% フルサイズで出力。
- **GFM 表組みアライメント**: Markdown 表組みの左寄せ `:---`、中央 `:---:`、右寄せ `---:` レンダリングに完全対応。

#### 🎨 デザイン & カラーモード
- **ハイコントラストカラーモード完全連動**: モーダル群 (ショートカット `F1`、バージョン情報、設定、Diff)、全画面スクロールバー、Front Matter 高明度カード (`bg-amber-50/60`), `prism` 構文ハイライトがライト/ダークテーマに完全適合。
- **標準カーソル固定**: タイトルバー領域ホバー時のカーソル変更を無効化 (`cursor-default`)。
