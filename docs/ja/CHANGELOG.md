# 更新履歴 (CHANGELOG)

QuMaEditor の主要な変更点およびリリース履歴です。

## [1.3.0] - 2026-08-12

### 🎨 UI・UX刷新 & App.tsxモジュール分割リファクタリング (v1.3.0)

- **タイトルバー・ステータスバーのレイアウト大刷新**:
  - ウィンドウ最上段（タイトルバー）の雑多なステータスバッジを整理し、ドラッグ領域 (`data-tauri-drag-region`) を中央に広大配置してウィンドウを掴んでの移動操作を大幅向上。
  - バージョン表示 (`v1.3.0`) を上段右側にシンプル配置。
  - ウィンドウ最小化・最大化・閉じるアイコンを標準形式 (`Minus` / `Square` / `X`) に刷新。
  - 保存完了ステータス (`saveStatus`) および「フォルダを開く」ボタンをメニューバー（コマンドリボン）の表示モード切替右隣・Zenモード左隣へスマート移動。
  - 最終更新日時 (`updatedAt`) を画面最下部のステータスバー左側統計エリアの末尾へ移動統合。
- **ドキュメント一覧（サイドバー）のマウスドラッグ幅リサイズ機能**:
  - サイドバー右端の境界線をマウスドラッグして幅を自由に変更可能（200px 〜 600px）。
  - 設定値は `localStorage` (`quma_sidebar_width`) に自動同期・記憶。
- **App.tsx のカスタムフック化・モジュール分割リファクタリング**:
  - `App.tsx` (約1,200行) を `useModalState`, `useDocumentManager`, `useFileOperations` の3つのカスタムフックへモジュール分離。
  - `App.tsx` の行数を約46%スリム化 (1,207行 $\rightarrow$ 654行) し、型安全性を高め可読性・保守性を飛躍的に向上。
- **使い方ガイドモーダル (`HelpGuideModal`) の全面アップデート**:
  - 最上部に「QuMaEditorとは？」のアプリ概要・特徴カードを設置し、基本操作ステップおよび文言を最新化。
- **CI / Release ワークフローの自動型同期機能強化**:
  - `.github/workflows/ci.yml` および `release.yml` に Specta による TypeScript バインディング生成ステップ (`npm run gen:specta`) を追加し、GitHub CI 上での型ギャップエラー落ちを根本防止。
- **Zenモード機能拡張アイデアのTODO策定**:
  - 音全ミュート、通知完全OFF、現在行フォーカス（カーソル行強調）、ポモドーロタイマー等の Zen モード拡張ロードマップを策定・登録。

## [1.2.3] - 2026-08-07

### 🐛 不具合修正 & インフラ・パイプライン強化 (v1.2.3)

- **Windows PowerShell コンソール画面の完全非表示化**: アプリ起動時および「QuMaEditorで開く」コンテキストメニュー登録時に、Windows 固有の `CREATE_NO_WINDOW` (`0x08000000`) フラグを付与。起動時に PowerShell の黒いコンソールウィンドウがポップアップ表示される問題を完全解消。
- **ヘルプガイドとバージョン情報の分離・最適化**: クイックガイド専用の `HelpGuideModal` を新設しヘッダーから直接呼び出し可能に。`AboutModal` はバージョン番号・正常稼働中ステータスバッジ・トラブルシューティング対処法のみにスリム化。
- **サイドバー項目への「エクスプローラーで開く」ボタン配置**: TitleBar のファイルメニューに加え、サイドバーの各ファイル項目ホバー時にも「対象フォルダをエクスプローラーで開く」ボタンを配置。
- **Rust バックエンドの全機能モジュール分割リファクタリング**: `src-tauri/src/lib.rs` (約750行) を機能単一責任原則に基づき `commands.rs`, `encoding.rs`, `file_io.rs`, `search.rs`, `diff.rs` の 5 つのモジュール構造へ再構築。`lib.rs` を約100行へ超スリム化し、保守性・可読性・ビルド性能を劇的改善。

## [1.2.2] - 2026-08-07

### ✨ UI・操作性大幅強化 (v1.2.2)

- **設定画面の「完全初期化」ボタンを下部左端に移動**: `SettingsModal` の「設定・データを完全初期化」ボタンを底部「完了」ボタン行の左端に移動。誤操作防止と UI整備を辺るレイアウトに変更。
- **プレビュー画面のCrtl+ホイールズーム対応**: `Preview` コンポーネントに `Ctrl + スクロールホイール` によるプレビュー拡大縮小機能を実装。ズーム範囲 50% 〜 300%、クリックでリセットバッジ表示。
- **ツールバーの太字・斜体・下線・消し線ボタンを「選択範囲に適用」に変更**: テキスト選択時はその範囲を `**...**` / `*...*` / `<u>...</u>` / `~~...~~` でラップ、非選択時はカーソル位置に挿入。フォーマット後のカーソル位置およびフォーカスも自動復元。
- **見出し (H1/H2/H3) ボタンを「カーソル行最初の行頭挿入」に変更**: 従来の末尾追加から変更し、現在カーソル行の行頭に `# ` / `## ` / `### ` マーカーを挿入。既存見出しがある場合は置換して切り替え。
- **PCtoFileFile・リモートファイル時に「対象フォルダをエクスプローラーで開く」機能追加**: `TitleBar` のファイルメニューにボタンを追加。PC上の実ファイル (`filePath` あり) 時のみ表示され、Rustネイティブコマンド (`open_folder_native`) でエクスプローラーを起動しファイル位置を開く。
- **ヘルプ画面に「LocalStorage 保護保存の仕組み」解説を追加**: `AboutModal` に LocalStorage とは何か・なぜ安全か・実ファイル保存との違いを比較表形式で図解。アプリ最大の目玉機能を初心者にも分かりやすく説明。

## [1.2.1] - 2026-08-06

### 🐛 ローカルファイルオープン・「送る」連携不具合の根本修正 ＆ デフォルト表示最適化 (v1.2.1)

- **起動時デフォルト表示モードを「編集のみ」に変更**: 起動時の初期表示モードを従来の分割表示 (`split`) から編集専用画面 (`editor`) に変更。
- **ローカルファイルオープン機能の型安全化・信頼性向上**: `tauri-specta` の型安全バインディング (`commands.readFileNative`) に一括刷新し、Rust ネイティブ読み込みにおける失敗ログの出力を強化。
- **Windows Startup / PowerShell 同期ブロック障害の解決**: Windows の PowerShell 処理をバックグラウンドスレッド (`spawn_blocking`) で非同期化し、起動フリーズを根本防止。
- **IPv4 ループバック (`127.0.0.1`) の完全固定**: `tauri.conf.json` および `vite.config.ts` の開発サーバーホストを `127.0.0.1` に明示固定し、Windows 環境での IPv6 名前解決の競合・接続ハングを排除。
- **サイドバー保存種別バッジ ＆ 削除ツールチップの明確化**: 左サイドバーのドキュメント一覧において、ファイルが `📁 PCファイル`（実ファイル）, `🌐 リモート`（URL参照）, `📦 LocalStorage`（アプリ内のみ保存）のいずれであるかを一目で識別できる視認性バッジを表示。また、削除アイコンのツールチップを `"LocalStorage から削除 (下書き破棄)"` に変更し、実ファイル削除でないことを明快化。
- **Front Matter 作成者名 (Author) 保護 ＆ 更新者 (UpdatedBy) 変更規則の最適化**: 作成者名 (`author`) を一度記録した後は自動上書きせず保護固定する仕様に変更（`"Unknown"` の時のみ手動設定変更が可能）。保存・編集時は設定画面の `defaultAuthor` または入力値により `updatedBy`（更新者）を更新。タイトルバーに `👤 作成`, `✍️ 更新者 (クリック変更可能)`, `🕒 更新日時` を可視化表示。
- **LocalStorage 肥大化防止 ＆ 自動ガベージコレクション (GC) 機構の導入**: ボスからのアドバイスに基づき、将来的な LocalStorage 容量制限 (5MB) 超過・`QuotaExceededError` を永久に防ぐ設計へ強化。ローカル PC 上の実ファイルに保存済みのドキュメントは、LocalStorage 保存時に全本文ではなく軽量メタデータ (`<!-- [STORAGE_SLIMMED_LOAD_FROM_DISK] -->`) へ自動スリム化。ファイル選択時に実ファイルからバックグラウンドで最新内容を自動全ロード復元する仕組みを構築。容量 2MB 超過時の自動 GC および緊急クリーンアップも完備。
- **Rust バックエンド単体テストの拡充 (全9件 100% PASS)**: `read_file_native` (エラーハンドリング/一時ファイル), `compute_text_diff_native`, `index_documents_native` / `search_documents_native`, `convert_utf8_to_encoding` (Shift_JIS/EUC-JP 相互変換) 等のユニットテストを追加し全件テストクリア。

## [1.2.0] - 2026-08-05

### 💾 ネイティブファイル直接保存・ストレージ可視化 & ビルド最適化 (v1.2.0)

- **直上書き保存 (`Ctrl + S`) ＆ 名前を付けて保存 (`Ctrl + Shift + S`)**: Tauri `dialog` / `fs` プラグインおよび Rust ネイティブ読込 (`read_file_native`) を統合。ローカル PC 上の実際の `.md` ファイルパス (`filePath`) を保持し、手動保存および打鍵後の自動保存タイマーで **元ファイルへの直接上書き保存** を実現。
- **Windows エクスプローラー右クリック「QuMaEditorで開く」自動登録**: アプリ起動時およびインストール時にエクスプローラーの右クリックコンテキストメニューへ「QuMaEditorで開く」を自動設定。
- **二重起動防止 (Single Instance)**: 既に起動している場合は二重起動をブロックし、既存の QuMaEditor ウィンドウを前面表示してファイルパスを新規タブとして一発オープン。
- **表示フォントサイズのプレビュー画面連動**: 設定画面での「基本フォントサイズ」変更がエディタ画面およびプレビュー画面の両方に即座に反映されるよう強化。
- **タブバーのスクロールバー完全消去**: タブ大量オープン時のスクロールバー表示をCSS隠蔽処理 (`[scrollbar-width:none]`) で消去しスタイリッシュ化。
- **内部ストレージ (LocalStorage / AppData) パス可視化 ＆ 肥大化対策**: 設定画面 (`SettingsModal`) に AppData 格納パス（コピーボタン付き）やリアルタイム使用量 (KB/件数) を表示。「一時キャッシュを整理」「初期状態にリセット」等のメンテナンスアクションを追加。
- **Vite ビルド警告の根本解消 (Code Splitting)**: `vite.config.ts` に Rollup の `manualChunks` コード分割を導入。1.5MB の巨大 JS ファイルを `vendor-react`, `vendor-icons`, `vendor-syntax` 等へ構造化分割し、ビルド警告を完全消去 (0 Warning)。
- **パッケージングバイナリの明示固定**: `Cargo.toml` に `[[bin]]` セクションを追加し、Tauri インストーラーが誤ったユーティリティバイナリ (`gen_specta.exe`) を選ばず、確実に `QuMaEditor.exe` をパッケージングするよう安定化。

## [1.0.0] - 2026-08-04

### 🚀 正式リリース (Initial Formal Release v1.0.0)

#### 🌟 コア機能 & Rust アクセラレーション
- **Tauri v2 + Rust Native 高速アーキテクチャ**: 低メモリ消費 (RAM ~35MB) と超軽量レスポンスを実現。
- **10MB+ 大容量ファイルストリーミング**: `read_file_chunk_native` によるメモリ溢れのない高速段階読み込み。
- **転置インデックス全文検索**: `LazyLock` を用いた Rust ネイティブ単語インデックス高速検索。
- **一括マルチスレッド文字コード変換**: `rayon` スレッドプールによる複数ファイル並列 UTF-8 変換。
- **高速テキスト Diff 比較演算**: `similar` クレートによる高速な行単位差分抽出。
- **文字コード自動判定 & 保存**: `encoding_rs` を用いた UTF-8 / Shift_JIS / EUC-JP 自動判定および CRLF/LF 改行保存。

#### 🔍 高度な検索 & ハイライト
- **キーワードハイライト検索**: 入力検索単語に一致する箇所を鮮やかな黄色バッジ (`<mark>`) で爆速強調表示。
- **YAML Front Matter タグ検索**: タイトル・本文に加え、Front Matter 内のタグ (`#ガイド` 等) での検索絞り込みに対応。
- **検索ヒット対象ファイル名の高コントラスト表示**: 対象ファイル名 (`hit.doc_title`) を太字の高コントラストカラー (`text-cyan-300` / `text-cyan-900`) でクッキリ表示。

#### 📄 プレビュー・印刷・ダイレクト PDF
- **ワンクリック・ダイレクト PDF ファイル保存**: 印刷ダイアログを起動せず、プレビュー描画スタイリングそのままにワンクリックで `.pdf` ファイルを直接生成・保存。
- **A4 フルサイズ印刷対応 (`Ctrl + P`)**: 印刷ダイアログ出力時、編集画面 (`Editor.tsx`) および全 UI パーツを `print:hidden` で完全に排除し、プレビュー文章のみを A4 100% フルサイズで出力。
- **GFM 表組みアライメント**: Markdown 表組みの左寄せ `:---`、中央 `:---:`、右寄せ `---:` レンダリングに完全対応。

#### 🎨 デザイン & カラーモード
- **ハイコントラストカラーモード完全連動**: モーダル群 (ショートカット `F1`、バージョン情報、設定、Diff)、全画面スクロールバー、Front Matter 高明度カード (`bg-amber-50/60`), `prism` 構文ハイライトがライト/ダークテーマに完全適合。
- **標準カーソル固定**: タイトルバー領域ホバー時のカーソル変更を無効化 (`cursor-default`)。
