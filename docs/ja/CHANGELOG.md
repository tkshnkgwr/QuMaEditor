# 更新履歴 (CHANGELOG)

QuMaEditor の主要な変更点およびリリース履歴です。

## [1.4.2] - 2026-08-21

### 📑 見出しアウトライン目次・LocalStorage実ファイル保存・Tabインデント・Markdown純化 (v1.4.2)

- **見出し構造（アウトライン/目次）ナビゲーションの追加 (`Sidebar / Navigation`)**:
  - サイドバーに「📁 ドキュメント」と「📑 目次 / アウトライン」の 2 タブ切り替えを新設。
  - Rust ネイティブ（`pulldown_cmark` offset + 二分探索）による行番号付き H1〜H6 見出し高速抽出。
  - レベルに応じた階層インデント、視覚的レベルバッジ（`H1`〜`H6`）、行番号表示、リアルタイム検索フィルターを完備。
  - 目次項目をクリックすると、エディタの該当行へカーソル移動＆中央スクロールし、プレビューも該当見出しへスムーズスクロールする双方向ジャンプ連動を実現。
- **LocalStorage作成中ドキュメントの「💾 PCファイルに保存」ボタン新設 (`File / Storage`)**:
  - 実ファイルパスが存在しないドキュメント（LocalStorage管理のみ）の編集中、StatusBar（フッター）上にワンクリックでローカル保存ダイアログを呼び出せる専用アクションボタンを設置。
- **エディタ内 Tab キーインデント＆箇条書き階層ネスト対応 (`Editor / List`)**:
  - テキストエリア内での `Tab` キー押下時のフォーカス移動を抑止。
  - 単一行での箇条書きプレフィックス自動階層化（`- ` ➔ `  - `、`1. ` ➔ `  1. `）、複数行選択時のブロックインデント、`Shift + Tab` でのアンインデントを完全サポート。
- **番号付きリスト（`<ol>`）＆多階層ネスト箇条書きのプレビュー表示修正 (`Preview / Markdown`)**:
  - `<ol>` 番号マーカーとテキストが複数行に分裂する不具合を修正。
  - 多階層ネストリストの箇条書きマーカー（disc ➔ circle ➔ square、1. ➔ a.）および印刷スタイルを最適化。
- **CSV プレビュー機能の完全撤廃＆Markdown 専用エディタ純化 (`Preview / CSV Drop`)**:
  - バックエンド（`csv.rs`、Spectaバインディング）およびフロントエンド（Preview、Editor、StatusBar）から CSV 固有のパース・プレビュー・状態管理ロジックを完全撤廃し、アプリのフットプリントを大幅にスリム化。
- **🧘 Zen集中執筆モード（Zen Mode）のヘルプガイド＆マニュアル拡充 (`Help / Docs`)**:
  - アプリ内ヘルプモーダルおよび操作マニュアルに、Zenモードの仕様（UI全非表示、中央タイポグラフィ、`Ctrl+Shift+Z` / `Esc`）を分かりやすく明記。

## [1.4.1] - 2026-08-18

- **印刷プレビューの根本改修＆複数ページ改ページ（Pagination）最適化**:
  - 用紙サイズ・印刷レイアウト（縦/横）の変更を即座にプレビューへ反映。
  - 印刷時タイトルヘッダーへのファイル名自動印字と QuMaEditor 印刷バッジ描画。
  - タスクリスト（チェックボックス枠・チェックマーク・打消し線）の鮮明印刷保証。
- **Mermaid ダイアグラムの印刷時 1 ページ自動縮小フィット（オートスケール）＆空白ページ根絶**:
  - 巨大・縦長な Mermaid 図であっても用紙 1 ページの高さ内に自動縮小して美しく収容。
  - 印刷エンジンでの外枠線残存および巨大な空白ページ発生を完全に解消。
- **複数ページプレビュー＆レイアウト切り替えの即時同期**:
  - `Preview` コンポーネントの CSS 表示制御化によるレイアウト切り替えゼロ遅延化。
  - エディタ設定（行間、フォント）のプレビュー完全連動。
- **Windows「送る (SendTo)」設定の完全削除**:
  - 不要なスタブおよび設定モーダル UI のクリーンアップ。

## [1.4.0] - 2026-08-18

### 🚀 Rust ネイティブ Markdown 自動整形・ゼロレイテンシ・CSV 高速化・モジュール分割 (v1.4.0)

- **Markdown 高速自動整形機能 (`Ctrl + Shift + F`)**:
  - Rust ネイティブエンジンにより、表組みの垂直整列、見出し前後の空行自動挿入、過剰連続空行の圧縮（コードブロック内は完全保護）を一瞬で実行する「✨ 整形」ボタン＆ショートカットを実装。
- **エディタ打鍵時のゼロレイテンシ化**:
  - 「編集のみ」モード時のプレビュー完全アンマウント・バイパス、および「分割表示」モード時のプレビュー解析遅延（Debounce / `useDeferredValue`）により、打鍵遅延ゼロの快適なタイピングを実現。
- **`Ctrl + E` カーソル位置・フォーカス自動復元**:
  - プレビュー表示から `Ctrl + E` またはヘッダー操作でエディタへ戻った際、直前のカーソル位置・行選択を自動復元しエディタへ即座にフォーカス。
- **Markdown プレビューでの Mermaid ダイアグラム リアルタイム描画＆ズーム**:
  - ````mermaid ... ```` 構文ブロックを自動検出し、フローチャート・シーケンス図・状態遷移図・クラス図等の美しい SVG 図をリアルタイム描画する `MermaidRenderer` を実装。
  - ズームコントローラー（50%〜600%）、大画面フルスクリーン拡大モーダル、ダーク/ライトテーマ自動連動、ワンクリック構文コードコピーを完備。
- **大容量 CSV ゼロコピー高速解析＆インタラクティブテーブル**:
  - 数万行の CSV も Rust ネイティブで高速パースし、型自動判別（文字型は左寄せ、日付は中央、数値型は右寄せ）＆クリックソート・検索フィルター付きプレビューテーブルを描画。
- **ドキュメント詳細統計ダッシュボードモーダル (`StatsModal`)**:
  - 文字数、単語数、行数、読了予想時間（分）、見出し数、リンク数をリアルタイム集計・グラフ表示するモーダルを新設（StatusBar クリックで呼び出し可能）。
- **外部プロセス更新検知＆選択時自動最新化・手動再読込 (`F5`)**:
  - 外部エディタでのファイル変更を `mtime` で自動検知しトースト通知・自動更新。手動でのディスク再読込 (`F5` / `Ctrl + R`) を実装。
- **保存ステータス表示の StatusBar 集約**:
  - TitleBar の保存状態表示を StatusBar（フッター）へ移動・集約し、UIをすっきり整理。
- **エディタカスタマイズ設定の拡張**:
  - 基本フォントサイズに加え、「行間 (Line Height)」「エディタフォントファミリー (Monospace / Sans-serif)」「タブ幅」の設定項目を追加。
- **1,000行超過防止モジュール分割リファクタリング**:
  - バックエンド `text_processing/`（`stats.rs`, `yaml.rs`, `structure.rs`, `csv.rs`, `formatter.rs`, `html_renderer.rs`）へ分割。
  - フロントエンド `useGlobalShortcuts.ts`, `ModalGroup.tsx`, `MarkdownRenderers.tsx` へ分割。
  - プロジェクト内の全ソースファイルが 1,000 行未満に収まり、責務が綺麗に整理。

  - `e.dataTransfer.dropEffect = 'copy'` を明示指定し、エクスプローラーからの禁止マーク（🚫）を解除。
  - アプリ全体にドラッグした際に見やすい案内が表示される全画面オーバーレイを導入。

### 🚀 Rust 転置インデックス検索・大容量ストリーミング＆メモリ GC (v1.3.0)

- **10MB+ 大容量ファイルのメモリ分割ストリーミング (`read_file_chunk_native`)**:
  - 巨大な Markdown ファイルを段階的に読み込み、初期メモリ消費量を大幅削減。
- **転置インデックス爆速全文検索 (`search_documents_native`)**:
  - メモリ内転置インデックスによるリアルタイム全文検索エンジンを実装。
- **自動ストレージスリム化 (Memory Slimming GC)**:
  - 保存済みドキュメントを LocalStorage 保存時に軽量プレースホルダーへ自動圧縮し、容量オーバーを防止。
