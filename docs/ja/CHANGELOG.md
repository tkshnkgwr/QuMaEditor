# 更新履歴 (CHANGELOG)

QuMaEditor の主要な変更点およびリリース履歴です。

## [1.2.0] - 2026-08-05

### 💾 ネイティブファイル直接保存・ストレージ可視化 & ビルド最適化 (v1.2.0)

- **直上書き保存 (`Ctrl + S`) ＆ 名前を付けて保存 (`Ctrl + Shift + S`)**: Tauri `dialog` / `fs` プラグインおよび Rust ネイティブ読込 (`read_file_native`) を統合。ローカル PC 上の実際の `.md` ファイルパス (`filePath`) を保持し、手動保存および打鍵後の自動保存タイマーで **元ファイルへの直接上書き保存** を実現。
- **Windows エクスプローラー右クリック「QuMaEditorで開く」自動登録**: アプリ起動時およびインストール時にエクスプローラーの右クリックコンテキストメニューへ「QuMaEditorで開く」を自動設定。
- **二重起動防止 (Single Instance)**: 既に起動している場合は二重起動をブロックし、既存の QuMaEditor ウィンドウを前面表示してファイルパスを新規タブとして一発オープン。
- **表示フォントサイズのプレビュー画面連動**: 設定画面での「基本フォントサイズ」変更がエディタ画面およびプレビュー画面の両方に即座に反映されるよう強化。
- **タブバーのスクロールバー完全消去**: タブ大量オープン時のスクロールバー表示をCSS隠蔽処理 (`[scrollbar-width:none]`) で消去しスタイリッシュ化。
- **内部ストレージ (LocalStorage / AppData) パス可視化 ＆ 肥大化対策**: 設定画面 (`SettingsModal`) に AppData 格納パス（コピーボタン付き）やリアルタイム使用量 (KB/件数) を表示。「一時キャッシュを整理」「初期状態にリセット」等のメンテナンスアクションを追加。
- **Vite ビルド警告の根本解消 (Code Splitting)**: `vite.config.ts` に Rollup の `manualChunks` コード分割を導入。1.5MB の巨大 JS ファイルを `vendor-react`, `vendor-icons`, `vendor-syntax` 等へ構造化分割し、ビルド警告を完全消去 (0 Warning)。
- **パッケージングバイナリの明示固定**: `Cargo.toml` に `[[bin]]` セクションを追加し、Tauri インストーラーが誤ったユーティリティバイナリ (`gen_specta.exe`) を選ばず、確実に `QuMaEditor.exe` をパッケージングするよう安定化。

## [1.1.0] - 2026-08-04

### 🛠️ ドキュメント・自動型生成 & テスト全完備 (v1.1.0)

- **Specta TypeScript 型自動生成環境 (`src/bindings.ts`)**: `specta` / `tauri-specta` を導入し、Rust 側の全 DTO および Tauri コマンド群から TypeScript 型定義を型安全に全自動出力・同期する環境を確立 (`npm run gen:specta`)。
- **TypeDoc フロントエンド API ドキュメント (`docs/typedoc/`)**: `typedoc` を導入し、IPC ブリッジ・型定義の全フロントエンド API HTML ドキュメント環境を自動出力構築 (`npm run docs:frontend`)。
- **RustDoc バックエンド HTML ドキュメント (`cargo doc`)**: 全 Rust モジュール・関数・DTO に RustDoc コメントを追加し、ネイティブコアライブラリドキュメントを完全生成。
- **Tauri v2 IPC 開発・テスト仕様書 (`docs/ja/TAURI_GUIDE.md`)**: Tauri の IPC 通信アーキテクチャ、パーミッション (Capabilities)、3 レイヤーテスト構築ガイドを完全作成。
- **Rust コアネイティブ単体テスト (Unit Tests)**: 全文検索、文字コード判定、Markdown パース、Text Diff 等を検証する全 5 件の単体テスト (`cargo test`) を作成し全件パス達成。

## [1.0.0] - 2026-08-04

### 🚀 正式リリース (Initial Formal Release v1.0.0)

#### 🌟 コア機能 & Rust アクセラレーション
- **Tauri v2 + Rust Native 高速アーキテクチャ**: 低メモリ消費 (RAM ~35MB) と超軽量レスポンスを実現。
- **10MB+ 大容量ファイルストリーミング**: `read_file_chunk_native` によるメモリ溢れのない高速段階読み込み。
- **転置インデックス全文検索**: `LazyLock` を用いた Rust ネイティブ単語インデックス高速検索。
- **一括マルチスレッド文字コード変換**: `rayon` スレッドプールによる複数ファイル並列 UTF-8 変換。
- **高速テキスト Diff 比較演算**: `similar` クレートによる高速な行単位差分抽出。
- **文字コード自動判定 & 保存**: `encoding_rs` を用いた UTF-8 / Shift_JIS / EUC-JP 自動判定および CRLF/LF 改行保存。

#### 🔍 高度な検索 & ハイライト
- **キーワードハイライト検索**: 入力検索単語に一致する箇所を鮮やかな黄色バッジ (`<mark>`) で爆速強調表示。
- **YAML Front Matter タグ検索**: タイトル・本文に加え、Front Matter 内のタグ (`#ガイド` 等) での検索絞り込みに対応。
- **検索ヒット対象ファイル名の高コントラスト表示**: 対象ファイル名 (`hit.doc_title`) を太字の高コントラストカラー (`text-cyan-300` / `text-cyan-900`) でクッキリ表示。

#### 📄 プレビュー・印刷・ダイレクト PDF
- **ワンクリック・ダイレクト PDF ファイル保存**: 印刷ダイアログを起動せず、プレビュー描画スタイリングそのままにワンクリックで `.pdf` ファイルを直接生成・保存。
- **A4 フルサイズ印刷対応 (`Ctrl + P`)**: 印刷ダイアログ出力時、編集画面 (`Editor.tsx`) および全 UI パーツを `print:hidden` で完全に排除し、プレビュー文章のみを A4 100% フルサイズで出力。
- **GFM 表組みアライメント**: Markdown 表組みの左寄せ `:---`、中央 `:---:`、右寄せ `---:` レンダリングに完全対応。

#### 🎨 デザイン & カラーモード
- **ハイコントラストカラーモード完全連動**: モーダル群 (ショートカット `F1`、バージョン情報、設定、Diff)、全画面スクロールバー、Front Matter 高明度カード (`bg-amber-50/60`), `prism` 構文ハイライトがライト/ダークテーマに完全適合。
- **標準カーソル固定**: タイトルバー領域ホバー時のカーソル変更を無効化 (`cursor-default`)。
