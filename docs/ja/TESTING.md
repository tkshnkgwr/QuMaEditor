# テスト方針・検証基準 (TESTING)

## 1. テスト方針
本プロジェクトでは以下の品質基準を満たす必要があります。

1. **静的解析・型安全性**: TypeScript の Strict チェックを通過し、`npm run lint` がエラーゼロであること。
2. **文字コード・改行コード相互検証**: `UTF-8`, `Shift_JIS`, `EUC-JP` のそれぞれの相互変換で文字欠損・破壊・文字化けが発生しないこと。
3. **描画・UI安定性**: Viteによるプロダクションビルドが正常完了し、リアルタイムプレビューと自動保存が遅延なく動作すること。

## 2. ローカル検証プロセス

```bash
# 1. 型定義と静的チェック
npm run lint

# 2. ビルドテスト
npm run build
```
