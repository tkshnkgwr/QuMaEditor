# セキュリティ方針 (SECURITY)

[English Version](../en/SECURITY.md) | **日本語版**

## 1. セキュリティ設計基準

1. **ローカル完結実行と外部通信の最小化**:
   - 通常のドキュメント編集・保存・検索・文字コード変換・ローカル要約はすべて端末内（クライアント／Rust ネイティブ層）で完結し、外部サーバーへドキュメントデータを送信しません。
   - **例外（AI自動要約の明示的利用時）**: ユーザーが設定画面で Google Gemini API キーを設定し、AI 要約生成を実行した場合に限り、指定された Gemini API エンドポイントへ対象テキストを送信します。
2. **XSS（クロスサイトスクリプティング）対策**:
   - Rust ネイティブ HTML レンダラー（`pulldown-cmark` + `syntect`）およびインライン拡張変換において、すべてのユーザー入力・タイトル・属性値に厳格な HTML エスケープを適用し、悪意あるスクリプト実行を防止しています。
   - React プレビューエンジン選択時にも `react-markdown` による安全なコンポーネント描画を行っています。
3. **アトミックファイル保存とローカルデータ保護**:
   - 実ファイル保存時は一時ファイルへの書き込みと `sync_all()` 後にアトミックリネームを実行し、クラッシュ時のファイル破損（0バイト化）を防止します。

## 2. 脆弱性の報告プロセス
セキュリティ上の問題を発見された場合は、公開の Issue ではなく直接開発チーム宛にご連絡ください。
