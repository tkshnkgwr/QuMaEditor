# 操作マニュアル (USER_GUIDE)

[English](docs/en/USER_GUIDE.md) | **日本語版**

## 1. 基本画面構成 (v1.4.1)

QuMaEditor は Windows デスクトップアプリケーション風の直感的な UI で構成されています。

1. **タイトルバー (Header)**:
   - 左側: サイドバー開閉ボタン、ドキュメントタイトル（クリックでインライン編集可能）、文字コードバッジ（`UTF-8`, `Shift_JIS`, `EUC-JP`）、改行コードバッジ (`LF`, `CRLF`)、文字数・行数カウンター。
   - 右側: テーマ切替（ライト/ダーク/システム）、バージョン情報 (`v1.4.1`)、設定ボタン、ウィンドウ操作（最小化・最大化・閉じる）。
   - 下部: 「ファイル」「テンプレート」「ヘルプ」ドロップダウンメニュー、表示モード切替（分割 / 編集のみ / プレビューのみ）、Zen 集中モード切替。
2. **入力補助ツールバー (Toolbar)**:
   - 見出し (H1~H3)、太字、斜体、下線、打消線、リスト、タスク、表組、インラインコード、コードブロック、引用、リンク、画像アップロード、水平線、現在日時挿入ボタン。
   - **✨ Markdown 自動整形 (`Ctrl+Shift+F`)**: 表組みの垂直整列、見出し前後の空行自動挿入、連続空行圧縮を一瞬で実行。
   - **選択範囲への適用**: テキストを選択した状態で太字・斜体等のボタンを押すと、選択テキストの前後が自動的に囲まれます。
   - **見出しの行頭挿入**: H1~H3 ボタンを押すと、現在カーソルがある行の行頭に見出しマーカー (`# `, `## `, `### `) が挿入・切り替えされます。
3. **ワークスペース (Editor & Preview)**:
   - **ゼロレイテンシ・タイピング**: 「編集のみ」モード時はプレビュー解析を完全バイパスし、超軽快な打鍵感を維持。
   - **`Ctrl + E` カーソル自動復元**: プレビューからエディタへ戻った際、直前のカーソル位置・選択範囲を自動復元。
   - **Mermaid リアルタイム描画 & ズーム**: フローチャートやシーケンス図を SVG 描画。`Ctrl + ホイール` またはツールバーで 50%〜600% 拡大縮小、フルスクリーン拡大表示に対応。
   - **CSV インタラクティブプレビュー**: CSV ファイルを開いた際、型自動判別（数値は右寄せ、日付は中央、文字は左寄せ）＆クリックソート・検索フィルター付きテーブルを描画。
4. **ステータスバー (Footer)**:
   - 保存ステータスバッジ（💾 実ファイルに保存 / 📦 アプリ内に保存）、行・列番号、文字数、単語数、読了目安時間、文字コード切替、保存用改行コードバッジ。
   - **詳細統計モーダルの起動**: 文字数・単語数エリアをクリックすると、より詳細な統計ダッシュボード (`StatsModal`) がポップアップします。

## 2. 文字コード・改行コードの操作

### ファイルを開く時

- タイトルバーの「ファイル」>「ファイルを開く (Ctrl+O)」、または**エクスプローラーからのドラッグ＆ドロップ**、右クリック「QuMaEditorで開く」等でファイルを開くと、**文字コードが自動判定**され、文字化けすることなく読み込まれます。
- **ドラッグ＆ドロップ機能**:
  - テキストファイル (`.md`, `.txt`, `.csv` 等) をドロップすると即座に新しいタブとして開かれます。
  - 画像ファイル (`.png`, `.jpg`, `.gif`, `.svg` 等) をドロップすると、Data URL に自動変換されカーソル位置へ画像タグが挿入されます。
- PC 上の実ファイルを開いている場合、タイトルバーの「ファイル」>「対象フォルダをエクスプローラーで開く」を選択すると、そのファイルが選択された状態で親フォルダーがエクスプローラーで開きます。

### 保存（エクスポート）する時

- ステータスバーの右側にある文字コードドロップダウンから保存したい文字コード（`UTF-8`, `Shift_JIS`, `EUC-JP`）を選択します。
- **Shift_JIS** を選択すると改行コードが自動的に **CRLF** に調整されます。
- **EUC-JP** または **UTF-8** を選択すると改行コードが自動的に **LF** に調整されます。
- `Ctrl + S` で PC 上の元ファイルへ直接上書き保存、`Ctrl + Shift + S` で名前を付けて保存ができます。

## 3. LocalStorage 二重保護機能と安全保存

### 「二重保護」ワークフロー

QuMaEditor は入力されたすべてのテキストを打鍵後 3 秒以内に**内部ストレージ (LocalStorage)** へ全自動バックグラウンド保存します。
- 万が一の停電やアプリクラッシュ時でもデータは 100% 保持されます。
- 完成したドキュメントは `Ctrl + S` で PC 上の実際の `.md` ファイルへ上書き保存することで、他アプリや Git 等での永続利用が可能です。
- 外部プロセス（VSCode やメモ帳など）でファイルが更新された場合は、`mtime` 検知により「外部で更新されました」と通知され、自動再読込または `F5` / `Ctrl+R` で手動再読込が可能です。

## 4. エディタ設定のカスタマイズ

右上の ⚙️ アイコンから設定画面を開き、以下の項目をカスタマイズできます：
- **基本フォントサイズ**: 12px 〜 24px
- **行間 (Line Height)**: 1.2（狭い）〜 2.2（非常に広い）
- **エディタフォント**: システム既定、等幅フォント (Monospace)、サンセリフ (Sans-serif)
- **タブ幅**: 2スペース / 4スペース
- **自動保存間隔**: 1秒 〜 10秒（または無効化）
- **見出しカラーテーマ**: 落ち着いた色、鮮やか、ハイコントラスト、モノトーン

## 5. 主要キーボードショートカット一覧

| ショートカット     | 機能・操作                                        |
| :----------------- | :------------------------------------------------ |
| `Ctrl + N`         | 新規 Markdown ドキュメントの作成                  |
| `Ctrl + O`         | ローカルファイル (.md, .txt, .csv) を開く         |
| `Ctrl + S`         | 実ファイルへの直上書き保存                        |
| `Ctrl + Shift + S` | 名前を付けて保存 (ローカルファイル保存)           |
| `Ctrl + Shift + F` | Markdown 高速自動整形 (表組み垂直整列・空行整理)  |
| `Ctrl + E`         | 表示モード切替 (編集のみ ↔ プレビューのみ)        |
| `F5` / `Ctrl + R`  | ディスクから最新状態を手動再読込                  |
| `Ctrl + P`         | A4 印刷 / PDF ダイアログの起動                    |
| `Ctrl + B`         | 太字書式の挿入 / 選択文字ラッピング               |
| `Ctrl + I`         | 斜体書式の挿入 / 選択文字ラッピング               |
| `Ctrl + Shift + Z` | Zen 集中執筆モードの切り替え                      |
| `F1`               | キーボードショートカット一覧ヘルプの表示          |
