# 操作マニュアル (USER_GUIDE)

[English](docs/en/USER_GUIDE.md) | **日本語版**

## 1. 基本画面構成 (v1.5.0)

QuMaEditor はモダンな Windows デスクトップアプリケーション風の直感的な UI で構成されています。

1. **タイトルバー (Header)**:
   - 左側: サイドバー開閉ボタン、ドキュメントタイトル（クリックでインライン編集可能）、文字コードバッジ（`UTF-8`, `Shift_JIS`, `EUC-JP`）、改行コードバッジ (`LF`, `CRLF`)、文字数・行数カウンター。
   - 右側: テーマ切替（ライト/ダーク/システム）、バージョン情報 (`v1.5.0`)、設定ボタン、ウィンドウ操作（最小化・最大化・閉じる）。
   - 下部: 「ファイル」「テンプレート」「ヘルプ」ドロップダウンメニュー、表示モード切替（分割 / 編集のみ / プレビューのみ）、Zen 集中執筆モード切替。
2. **左サイドバー (Sidebar & Outline)**:
   - **📁 ドキュメント一覧タブ**: LocalStorage 内および開いているドキュメントの切り替え・検索・タグ絞り込み・お気に入り登録・削除。
   - **📑 目次 / アウトラインタブ**: ドキュメント内の見出し（H1〜H6）を高速自動抽出し、階層インデントツリーで表示。各見出しをクリックするとエディタの該当行へカーソル移動＆中央スクロールし、プレビューも該当見出しへスムーズジャンプ。
3. **入力補助ツールバー (Toolbar)**:
   - 見出し (H1~H3)、太字、斜体、下線、打消線、リスト、タスク、表組、インラインコード、コードブロック、引用、リンク、画像アップロード、水平線、現在日時挿入ボタン。
   - **Mermaid 雛形挿入メニュー**: ツールバーのネットワークアイコンをクリックすると、フローチャート (`flowchart TD`)、シーケンス図 (`sequenceDiagram`)、状態遷移図 (`stateDiagram-v2`)、クラス図 (`classDiagram`)、ER図 (`erDiagram`)、マインドマップ (`mindmap`)、ガントチャート (`gantt`)、Git グラフ (`gitGraph`) の8大ダイアグラム雛形をカーソル位置へワンクリック挿入可能。
   - **✨ Markdown 自動整形 (`Ctrl+Shift+F`)**: 表組みの垂直整列、見出し前後の空行自動挿入、連続空行圧縮を一瞬で実行。
   - **選択範囲への適用**: テキストを選択した状態で太字・斜体等のボタンを押すと、選択テキストの前後が自動的に囲まれます。
   - **見出しの行頭挿入**: H1~H3 ボタンを押すと、現在カーソルがある行の行頭に見出しマーカー (`# `, `## `, `### `) が挿入・切り替えされます。
   - **文字修飾 Undo/Redo 完全連動**: 太字・斜体・下線（ショートカットまたはツールバーボタン）による文字装飾・挿入は、ブラウザのネイティブ Undo 履歴と完全連動（`Ctrl + Z` で装飾前の状態へワンステップで復元、`Ctrl + Y` でやり直し可能）。ボタン押下時もテキストエリアの選択範囲やフォーカスを維持。
4. **ワークスペース (Editor & Preview)**:
   - **2画面並べて比較編集・プレビュー (デュアルペイン)**: 最大2つのドキュメントを横に並べて同時に比較・編集可能。サイドバーやタブの右クリックから「右ペインで開く」を選択、またはタブバー右端の「2画面並べる」ボタンで起動。左右で編集・プレビューモードが連動し、クリックした側のファイルにフォーカスが追従。
   - **エディタ内 Tab インデント＆箇条書きネスト**: Tab キー押下時のフォーカス外れを抑止。単一行での箇条書き階層化（`- ` ➔ `  - `）、複数行ブロックインデント、`Shift + Tab` によるアンインデントに対応。
   - **ゼロレイテンシ・タイピング**: 「編集のみ」モード時はプレビュー解析を完全バイパスし、超軽快な打鍵感を維持。
   - **`Ctrl + E` カーソル自動復元**: プレビューからエディタへ戻った際、直前のカーソル位置・選択範囲を自動復元。
   - **PowerShell 構文ハイライト強化**: コードブロック（`powershell`, `pwsh`, `ps`, `posh`, `ps1`）のパラメータ引数（`-Path` 等の属性カラー）、比較演算子（`-eq` 等のキーワードカラー）、数値リテラル、特殊変数（`$_`, `$env:PATH` 等）を VS Code 準拠の配色で美しくハイライト。
   - **Mermaid リアルタイム描画 & ズーム・SVG保存**: フローチャートやシーケンス図を SVG 描画。ツールバーのズーム操作（50%〜600% / 100%↔200% トグル）、大画面フルスクリーン拡大表示、構文エラー時の分かりやすい日本語通知、ダイアグラム単体の **SVG 画像ダウンロード保存**、構文コードコピーに対応。スタンドアロン HTML エクスポート時にも図が自動描画されます。
5. **ステータスバー (Footer)**:
   - 保存ステータスバッジ（💾 実ファイルに保存 / 📦 アプリ内に保存）。
   - **「💾 PCファイルに保存」ボタン**: LocalStorage のみで管理されているドキュメントの編集中、ワンクリックで実ファイル保存ダイアログを起動。
   - **日本語校正 ＆ 記法Lint**: 画面左下に検出結果（連続助詞、表記ゆれ、未閉じ括弧/コードブロック等）を表示。カーソルを合わせると「日本語校正＆記法Lint検出結果」ツールチップが表示され、クリックで指摘一覧フライアウトを展開可能。
   - 行・列番号、文字数、単語数、読了目安時間、文字コード切替、保存用改行コードバッジ。
   - **詳細統計モーダルの起動**: 文字数・単語数エリアをクリックすると、より詳細な統計ダッシュボード (`StatsModal`) がポップアップします。

## 2. 🧘 Zen 集中執筆モード（Zen Mode）

文章の思考・執筆に 100% 没入するためのフルスクリーン集中環境です。

### 特徴
- **全 UI の自動非表示**: タイトルバー、ツールバー、サイドバー、ステータスバーをすべて隠し、余計な視覚的ノイズを完全排除。
- **快適な中央レイアウト**: 幅広ディスプレイでも視線移動が疲れにくいよう、テキストエリアを美しく中央配置。
- **即時復帰**: エディタ内で通常通りキーボード入力でき、いつでもワンキーで元の作業画面に戻れます。

### 操作方法
- **起動**: ショートカットキー <kbd>Ctrl + Shift + Z</kbd> または 上部メニュー「集中執筆」をクリック。
- **解除**: <kbd>Esc</kbd> キーを押すか、画面右上の浮遊ボタン「Zenモード解除 (Esc)」をクリック。

## 3. 🔀 2画面並べて比較編集・プレビュー（デュアルペイン）

2つの Markdown ファイルを左右に並べて、内容を比較しながら同時に編集・プレビューできるマルチタスク環境です。

### 特徴
- **2ファイル同時編集**: 左ペインと右ペインに別々のファイルを開き、両方を同時に編集可能。
- **表示モード連動**: 「編集モード」では左右両ペインともエディタ表示、「プレビューモード」では左右両ペインともプレビュー表示になります。2画面表示中は誤操作を防ぐため従来の 4 分割表示は自動抑止されます。
- **直感的なフォーカス切替**: 左ペインまたは右ペインをクリックするとアクティブドキュメントが切り替わり、ツールバーの文字装飾やステータスバーの保存・文字数表示がフォーカス中のファイルに追従します。
- **タブ連動ロード**: 2画面表示中にタブをクリックすると、現在アクティブなペイン（左または右）にそのタブの内容がロードされます。

### 操作方法
- **右ペインで開く**:
  - サイドバーのファイル一覧で対象ノートを**右クリック** ➔ **「右ペインで開く (並べて比較)」** を選択。
  - 上部タブバーのタブを**右クリック** ➔ **「右ペインで開く (並べて比較)」** を選択。
  - またはタブバー右端の **「2画面並べる」** ボタンをクリック。
- **並べて表示を解除**:
  - 右ペイン上部の **「✕」** ボタンをクリック。
  - またはタブバー右端の **「2画面解除」** ボタンをクリック。
  - または右ペインで開いているファイルのタブを閉じると自動的に 1 画面へ復帰します。

## 4. 文字コード・改行コードの操作

### ファイルを開く時

- タイトルバーの「ファイル」>「ファイルを開く (Ctrl+O)」、または**エクスプローラーからのドラッグ＆ドロップ**、右クリック「QuMaEditorで開く」等でファイルを開くと、**文字コードが自動判定**され、文字化けすることなく読み込まれます。
- **ドラッグ＆ドロップ機能**:
  - テキストファイル (`.md`, `.txt` 等) をドロップすると即座に新しいタブとして開かれます。
  - 画像ファイル (`.png`, `.jpg`, `.gif`, `.svg` 等) をドロップすると、Data URL に自動変換されカーソル位置へ画像タグが挿入されます。
- PC 上の実ファイルを開いている場合、タイトルバーの「ファイル」>「対象フォルダをエクスプローラーで開く」を選択すると、そのファイルが選択された状態で親フォルダーがエクスプローラーで開きます。

### 保存（エクスポート）する時

- ステータスバーの右側にある文字コードドロップダウンから保存したい文字コード（`UTF-8`, `Shift_JIS`, `EUC-JP`）を選択します。
- **Shift_JIS** を選択すると改行コードが自動的に **CRLF** に調整されます。
- **EUC-JP** または **UTF-8** を選択すると改行コードが自動的に **LF** に調整されます。
- `Ctrl + S` で PC 上の元ファイルへ直接上書き保存、`Ctrl + Shift + S` で名前を付けて保存ができます。

## 5. LocalStorage 二重保護機能と安全保存

### 「二重保護」ワークフロー

QuMaEditor は入力されたすべてのテキストを打鍵後 3 秒以内に**内部ストレージ (LocalStorage)** へ全自動バックグラウンド保存します。
- 万が一の停電やアプリクラッシュ時でもデータは 100% 保持されます。
- 完成したドキュメントは `Ctrl + S` または StatusBar の「💾 PCファイルに保存」で PC 上の実際の `.md` ファイルへ保存することで、他アプリや Git 等での永続利用が可能です。
- 外部プロセス（VSCode やメモ帳など）でファイルが更新された場合は、`mtime` 検知により「外部で更新されました」と通知され、自動再読込または `F5` / `Ctrl+R` で手動再読込が可能です。

## 6. エディタ設定のカスタマイズ

右上の ⚙️ アイコンから設定画面を開き、3 つの専用タブで細かくカスタマイズできます：

### 🎨 全般・外観タブ (`GeneralTab`)
- **基本フォントサイズ**: 12px 〜 24px（スライダー調整）
- **行間 (Line Height)**: 1.2（狭い）〜 2.2（非常に広い）
- **エディタフォント**: システム既定、等幅フォント (Monospace)、サンセリフ (Sans-serif)
- **タブ幅**: 2スペース / 4スペース
- **自動保存間隔**: 1秒 〜 10秒（または無効化）
- **見出しカラーテーマ**: 落ち着いた色、鮮やか、ハイコントラスト、モノトーン
- **スマートペースト (URL自動リンク化)**: テキスト選択中の URL 貼り付け時に `[テキスト](URL)` へ自動変換（トグル）
- **コードブロック配色テーマ**: VS Code Dark+, Dracula, Nord, Monokai, One Dark, Prism から選択

### 🤖 AI設定タブ (`AiTab`)
- **Gemini API キー**: Google AI Studio で取得した API キーを設定（マスク表示・表示切替対応）
- **AI 要約モデル選択**: 最新の推奨モデル（`gemini-2.5-flash`、`gemini-2.5-pro`、`gemini-2.0-flash` 等）から自由に選択。カスタムモデルの直接入力も可能
- **カスタム Base URL**: 社内プロキシやカスタムエンドポイント経由での接続に対応
- **要約ルール (プロンプトカスタマイズ)**: 生成される要約のトーンや文字数目安、フォーマット指示を自由に調整
- **接続テスト**: 設定した API キーと選択モデルで即座に疎通テストを実施し、成否をリアルタイム確認

### 💾 ストレージ管理タブ (`StorageTab`)
- **使用量サマリー**: LocalStorage の総使用量、保存済みドキュメント件数、画像アセット件数を可視化
- **ZIP一括エクスポート**: 保存されている全ドキュメントおよび画像を単一の ZIP アーカイブとして PC へ一括保存
- **データ初期化**: 必要に応じて LocalStorage のキャッシュ・データを安全に初期化

## 7. 🔍 日本語校正 ＆ 記法Lint 機能（リアルタイム検出）

文章の品質向上と Markdown 構文ミスの早期発見を支援するため、Rust ネイティブによる高速なバックグラウンド校正・Lint エンジンを搭載しています。

### 特徴
- **打鍵遅延ゼロの非同期解析**: テキスト入力の快適性を一切損なわないよう、Rust バックエンド（`proofreading.rs`）が別スレッドで非同期に構文解析を実行。
- **直感的なステータスバー表示**: 画面左下に検出結果件数を表示。マウスカーソルを合わせると「**日本語校正＆記法Lint検出結果**」のツールチップが表示されます。
- **指摘一覧フライアウト ＆ ワンクリックジャンプ**:
  - ステータスバーの校正表示をクリックすると、検出された問題の一覧フライアウトが展開。
  - 各項目をクリックすると、エディタ内の該当行・該当文字位置へ瞬時にカーソルが移動し、推奨される修正案を確認できます。

### 主な検査ルール一覧

| 検査分類 | 項目名           | 検出内容と具体例                                                                 |
| :------- | :--------------- | :------------------------------------------------------------------------------- |
| **文法** | 連続助詞の検出   | 同一文内で助詞「の」が3回以上連続して出現する冗長な表現（例: 「私の友人の兄の車」） |
| **表記** | 表記ゆれの検出   | 同一文書内で「サーバー / サーバ」「ユーザー / ユーザ」などの長音有無が混在するケース |
| **記法** | 未閉じ括弧の検出 | 「」、『』、（）、【】 などの開き括弧が閉じられていない不整合                     |
| **記法** | 未閉じブロック   | ```` ``` ```` で始まるコードブロックが文書末尾まで閉じられていない構文エラー     |

## 8. 🤖 AI自動要約機能と Front Matter 管理

QuMaEditor は、Google Gemini API を活用した高度な AI 要約機能と、Obsidian / 静的サイトジェネレーター互換の YAML Front Matter 連携を搭載しています。

### 特徴
- **ハイブリッド要約エンジン**:
  - API キー設定時は、選択された Gemini モデルによる高精度な文脈把握要約を生成。
  - API キー未設定時やネットワーク不通時は、本文の構造（見出し・先頭パラグラフ・キーセンテンス）を解析するローカル抽出フォールバック要約が自動で起動。
- **Front Matter への完全統合**:
  - 要約結果は Markdown 冒頭の YAML Front Matter（`summary:` および `summary_type:`）に自動記録。
  - Rust ネイティブ YAML パーサーおよびフロントエンドの両方で型安全に読み書き可能。
- **直感的な UI 連動**:
  - **エディタ**: Front Matter パネル内に「🤖 AI要約生成」ボタンを表示。生成後は要約カードとモデル名バッジが表示され、手動でのインライン編集・再生成・削除がワンクリックで可能。
  - **プレビュー**: プレビュー上部のメタデータカード内に要約文とモデルバッジが美しく表示。
