# 操作マニュアル (USER_GUIDE)

## 1. 基本画面構成

QuMaEditor は Windows デスクトップアプリケーション風の直感的な UI で構成されています。(バージョン: v1.2.2)

1. **タイトルバー**:
   - 左側: サイドバー開閉ボタン、ドキュメントタイトル（クリックでインライン編集可能）、リモートバッジ、文字コードバッジ（`UTF-8`, `Shift_JIS`, `EUC-JP`）、改行コードバッジ (`LF`, `CRLF`)、作成者/更新者情報、保存ステータス。
   - 右側: テーマ切替（ライト/ダーク/システム）、バージョン情報 (`v1.2.2`)、設定ボタン、ウィンドウ操作（最小化・最大化・閉じる）。
   - 下部: 「ファイル」「テンプレート」「ヘルプ」ドロップダウンメニュー、表示モード切替（分割/編集のみ/プレビューのみ）、Zen集中モード切替。
2. **入力補助ツールバー**:
   - 見出し (H1~H3)、太字、斜体、下線、打消線、リスト、タスク、表組、インラインコード、コードブロック、引用、リンク、画像アップロード、水平線、現在日時挿入ボタン。
   - **選択範囲への適用**: テキストを選択した状態で太字・斜体・下線・打消線等のボタンを押すと、選択テキストの前後が自動的に囲まれます（未選択時はカーソル位置に挿入）。
   - **見出しの行頭挿入**: H1~H3 ボタンを押すと、現在カーソルがある行の最先頭に見出しマーカー (`# `, `## `, `### `) が挿入・切り替えされます。
3. **ワークスペース (エディタ & プレビュー)**:
   - **プレビュー画面の Ctrl + ホイールズーム**: プレビューエリア上で `Ctrl + スクロールホイール` を操作すると、プレビュー文字サイズを 50% 〜 300% の範囲でスムーズに拡大縮小できます。拡大縮小中は右上に％表示とリセットボタンが表示されます。
4. **ステータスバー**:
   - 現在の行・列番号、文字数、単語数、読了目安時間、文字コード切替ドロップダウン、保存用改行コードバッジ (LF / CRLF)。

## 2. 文字コード・改行コードの操作

### ファイルを開く時
- タイトルバーの「ファイル」>「ファイルを開く (Ctrl+O)」またはエクスプローラーからのドラッグ＆ドロップ、右クリック「QuMaEditorで開く」等でファイルを開くと、**文字コードが自動判定**され、文字化けすることなく読み込まれます。
- PC 上の実ファイルを開いている場合、タイトルバーの「ファイル」>「対象フォルダをエクスプローラーで開く」を選択すると、そのファイルが存在する親フォルダーをエクスプローラーで即座に開くことができます。

### 保存（エクスポート）する時
- ステータスバーの右側にある文字コードドロップダウンから保存したい文字コード（`UTF-8`, `Shift_JIS`, `EUC-JP`）を選択します。
- **Shift_JIS** を選択すると改行コードが自動的に **CRLF** に調整されます。
- **EUC-JP** または **UTF-8** を選択すると改行コードが自動的に **LF** に調整されます。
- `Ctrl + S` で PC 上の元ファイルへ直接上書き保存、`Ctrl + Shift + S` で名前を付けて保存ができます。

## 3. LocalStorage 二重保護機能と安全保存

### 「二重保護」ワークフロー
QuMaEditor は入力されたすべてのテキストを打鍵後 3 秒以内に**内部ストレージ (LocalStorage)** へ全自動バックグラウンド保存します。
- 万が一の停電やアプリ障害時でもデータは 100% 保持されます。
- 完成したドキュメントは `Ctrl + S` で PC 上の実際の `.md` ファイルへ上書き保存することで、他アプリや Git 等での永続利用が可能です。
- アプリ上部の「ヘルプ」>「バージョン情報」ダイアログから、LocalStorage 保存と実ファイル保存の仕組み・比較表をいつでも確認できます。

## 4. Yama YAML Front Matter & タグの設定操作

### メタデータ保護エリアの表示・隠し
- エディタの上部には **「YAML Front Matter (保護領域)」** ヘッダーが配置されています。
- `title`（タイトル）、`created`（作成日時）、`updated`（更新日時）、`encoding`（文字コード）は、エディタ上での誤入力・誤消去を防ぐため**直接編集不可（保護状態）**になっています。
- ヘッダーをクリックすると、フロントマターの表示 / 折りたたみを切り替えることができます。

### タグ (tags) の設定方法
- フロントマター内の **tags** 項目のみ、専用UIから自由に追加・削除が可能です。
- **タグの追加**: 「+ タグを追加」ボタンをクリックし、タグ名を入力して Enterキーまたは「追加」ボタンを押します。
- **タグの削除**: 設定済みタグバッジの右側にある `x` ボタンをクリックすると削除できます。

## 5. キーボードショートカットヘルプ機能

### ショートカット確認モーダルの起動
- アプリ上部のメニューバーで **「ヘルプ」>「キーボードショートカット」** を選択するか、キーボードの <kbd>F1</kbd> キーを押します。
- カテゴリ別（ファイル＆ドキュメント操作、テキスト装飾・フォーマット、表示＆ヘルプ）に利用可能な全キーボードショートカットを確認できます。
