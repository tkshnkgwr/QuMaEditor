# 操作マニュアル (USER_GUIDE)

## 1. 基本画面構成

Markdown エディタはWindowsアプリケーション風の直感的なUIで構成されています。

1. **タイトルバー**:
   - 左側: サイドバー開閉ボタン、ドキュメントタイトル（ダブルクリックまたはペンアイコンで編集可能）、文字コードバッジ（`UTF-8`, `Shift_JIS`, `EUC-JP`）、保存ステータス。
   - 右側: バージョン情報 (`v1.2.0`)、設定ボタン、ウィンドウ装飾。
   - 下部: 「ファイル」「編集」「表示」「挿入」「テンプレート」ドロップダウンメニュー。
2. **入力補助ツールバー**:
   - 見出し (H1~H3)、太字、斜体、下線、打消線、リスト、タスク、コード、表組、画像、リンク等のワンクリック挿入ボタン。
3. **ワークスペース**:
   - 分割ビュー（左: エディタ / 右: プレビュー）、エディタのみ、プレビューのみの切替が可能。
4. **ステータスバー**:
   - 現在の行・列番号、文字数、単語数、読了目安時間、文字コード切替ドロップダウン、保存用改行コードバッジ (LF / CRLF)。

## 2. 文字コード・改行コードの操作

### ファイルを開く時
- タイトルバーの「ファイル」>「開く (Ctrl+O)」またはサイドバーからローカルファイル (.md / .txt) を選択すると、**文字コードが自動判定**され、文字化けすることなく読み込まれます。

### 保存（エクスポート）する時
- ステータスバーの右側にある文字コードドロップダウンから保存したい文字コード（`UTF-8`, `Shift_JIS`, `EUC-JP`）を選択します。
- **Shift_JIS** を選択すると改行コードが自動的に **CRLF** に調整されます。
- **EUC-JP** または **UTF-8** を選択すると改行コードが自動的に **LF** に調整されます。
- 「ファイル」>「エクスポート (.md)」を実行すると指定したエンコーディングのファイルが保存されます。

## 3. Yama YAML Front Matter & タグの設定操作

### メタデータ保護エリアの表示・隠し
- エディタの上部には **「YAML Front Matter (保護領域)」** ヘッダーが配置されています。
- `title`（タイトル）、`created`（作成日時）、`updated`（更新日時）、`encoding`（文字コード）は、エディタ上での誤入力・誤消去を防ぐため**直接編集不可（保護状態）**になっています。
- ヘッダーをクリックすると、フロントマターの表示 / 折りたたみを切り替えることができます。

### タグ (tags) の設定方法
- フロントマター内の **tags** 項目のみ、専用UIから自由に追加・削除が可能です。
- **タグの追加**: 「+ タグを追加」ボタンをクリックし、タグ名を入力して Enterキーまたは「追加」ボタンを押します。
- **タグの削除**: 設定済みタグバッジの右側にある `x` ボタンをクリックすると削除できます。
- 設定したタグは Markdown ファイルのエクスポート (.md) 時に YAML ヘッダーとして自動的に出力されます。

## 4. キーボードショートカットヘルプ機能

### ショートカット確認モーダルの起動
- アプリ上部のメニューバーで **「ヘルプ」>「キーボードショートカット」** を選択するか、キーボードの <kbd>F1</kbd> キーを押します。
- カテゴリ別（ファイル＆ドキュメント操作、テキスト装飾・フォーマット、表示＆ヘルプ）に利用可能な全キーボードショートカットを確認できます。
- モーダルは <kbd>Esc</kbd> キーまたは「閉じる」ボタンでいつでも閉じられます。
