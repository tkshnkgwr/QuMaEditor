# 貢献ガイドライン (CONTRIBUTING)

[English Version](../en/CONTRIBUTING.md) | **日本語版**

## 1. コミットメッセージ規約

コミットメッセージは以下の接頭辞を使用し、日本語で変更内容を明確に記述してください。

- `feat:` 新機能の追加 (例: `feat: Shift_JIS エクスポート対応を追加`)
- `fix:` バグ修正 (例: `fix: 外部変更監視時の多重リロードを修正`)
- `docs:` ドキュメントの修正・更新
- `style:` コードの意味に影響を与えないフォーマット変更
- `refactor:` リファクタリング
- `chore:` ビルド設定・リリース作業等

## 2. コードスタイルの原則

- TypeScript strict モードに準拠すること。
- UIコンポーネント内のコメントは日本語で分かりやすく記述すること。
