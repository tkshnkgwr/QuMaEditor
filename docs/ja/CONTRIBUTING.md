# 貢献ガイドライン (CONTRIBUTING)

## 1. コミットメッセージ規約

コミットメッセージは以下の接頭辞を使用してください。

- `feat:` 新機能の追加 (例: `feat: Add Shift_JIS export support`)
- `fix:` バグ修正
- `docs:` ドキュメントの修正・更新
- `style:` コードの意味に影響を与えないフォーマット変更
- `refactor:` リファクタリング

## 2. コードスタイルの原則

- TypeScript strict モードに準拠すること。
- UIコンポーネント内のコメントは日本語で分かりやすく記述すること。
