## 🎯 完了済みタスク (Completed)

### 次期リリース版 (開発完了)

- [x] **Markdownプレビューの完全Rust化 (`pulldown-cmark` + `syntect`) (`Performance / Rust`)**: JavaScript 側の描画負荷を完全撤廃。長大文書でも打鍵遅延ゼロ・常に60fpsの高速ネイティブHTML生成、Mermaidダイアグラム自動描画、双方向タスクリスト操作（`data-task-index`）を完全統合。
- [x] **大容量編集用Ropeデータ構造の導入 (`ropey`) (`Performance / Rust`)**: Bツリーベースの Rope データ構造モジュールを Rust バックエンドに新設。100MB級ファイルでもメモリ断片化やコピーコストを抑え、$O(\log N)$ での高速挿入・削除・行スライス取得を実現。
- [x] **外部変更監視のRustネイティブ化 (`notify`) (`Performance / Rust`)**: OSカーネル直結（`ReadDirectoryChangesW` / IOCP）の `notify` ウォッチャーを実装。自プロセス保存フィルタリングと連携し、CPU負荷0%＆保存時誤検知ゼロ化を達成。
- [x] **ワークスペース横断の高速全文検索 (`rayon`) (`Performance / Rust`)**: `rayon` によるマルチスレッド並列処理を導入。インメモリのドキュメント検索に加え、実ディレクトリ・フォルダ内のファイルを並列走査してタイピング即時に該当行を爆速抽出する `search_workspace_dir_native` を新設。
- [x] **タイプライター・スクロール (`ZenMode / Editor`)**: 入力中のカーソル行を画面の垂直中央高さに自動維持し、視線・首の上下移動を最小化するタイプライタースクロール機能を実装。設定モーダルで有効/無効を切り替え可能。
- [x] **実ファイル・ストレージ双方向同期のRust統合管理 (`FileSyncManager`) (`Performance / Rust`)**: フロントエンドと OS ファイルシステム間の同期状態、自プロセス保存中ロック、最新 mtime の一元管理を行うエンジンを新設。レースコンディションと外部更新誤検知を構造的に根絶。
- [x] **アトミックファイル書き込み ＆ mtime完全保証 (`atomic_write`) (`Performance / Rust`)**: 同一ディレクトリ内の一時ファイルへの先行書き込みと同期（`sync_all`）後、OSレベルのアトミックリネーム置換を実行。ファイル破損（0バイト化）リスクを0%にし、保存直後のミリ秒精度 mtime を即座に保証返却。
- [x] **ドキュメント差分比較のRustネイティブ化 (`similar`) (`Performance / Rust`)**: 行単位および単語単位のインライン詳細差分（`inline_changes`）を Rust 側で高速計算。Old/New行番号、追加・削除行数の正確な集計、単語レベルのハイライト表示を完備した詳細差分モーダルを実装。
- [x] **複数ノート一括エクスポート ＆ ZIP圧縮のRust化 (`zip`) (`Performance / Rust`)**: `zip` クレートを用いた高速 Deflate 圧縮エンジンを実装。全ドキュメントや埋め込みアセットをメモリ効率良く単一 ZIP アーカイブへ一括エクスポートする機能を設定モーダルに追加。
- [x] **日本語校正 ＆ 構文lintの非同期Rustバックグラウンド解析 (`proofreading`) (`Performance / Rust`)**: 入力遅延を一切発生させず、連続助詞・表記ゆれ（サーバ/サーバー等）・未閉じ括弧・未閉じコードブロックをバックグラウンドで高速解析。ステータスバーから指摘件数および推奨修正案を即座に確認可能。
- [x] **Mermaid図の構文検証 ＆ SVG差分キャッシュ最適化 (`mermaid_validator`) (`Performance / Rust`)**: ダイアグラム構文の事前検証と SHA-256 ハッシュによる SVG インメモリキャッシュを導入。未変更ダイアグラムの不要な再レンダリングコストを根絶し、ダイアグラム種別バッジ表示もサポート。
- [x] **メモリマップドファイル (mmap) による超巨大ファイルのゼロコピー瞬時オープン (`memmap2`) (`Performance / Rust`)**: OS の仮想メモリページキャッシュに直結し、GB 級の巨大テキストやログファイルでもヒープ消費ゼロ・0秒で瞬時オープン＆部分スライス読み込みを可能にするエンジンを新設。
- [x] **ワークスペースフォルダ高速走査 ＆ ファイルツリー構築の並列Rust化 (`ignore`) (`Performance / Rust`)**: `.gitignore` や隠し属性に完全準拠し、数万ファイル規模のプロジェクトフォルダをマルチスレッド並列で 0.05 秒走査してツリー構造を即時構築するエンジンを新設。
