## 🎯 完了済みタスク (Completed)

### v1.0.0 正式リリース版 (2026-08-04)
- [x] **Tauri v2 + Rust バックエンド移行**: 高速ネイティブデスクトップアプリ構造。
- [x] **タイトルバー制御 & カーソル固定**: ドラッグ移動 (`data-tauri-drag-region`)、最小化/最大化/閉じるアクション、標準カーソル固定 (`cursor-default`)。
- [x] **自動保存ディバウンス**: キー入力中の保存キャンセルとタイピング停止後 3,000ms での自動保存。
- [x] **GFM 表組み配置対応**: 左寄せ `:---`、中央 `:---:`、右寄せ `---:` レンダリング。
- [x] **カラーモード全面向上**: Front Matter 高明度カード (`bg-amber-50/60`), インラインコード/コードブロック `prism` スタイル, ヘルプダイアログ・設定画面 `isDark` 適用, 全画面スクロールバー連動。
- [x] **検索強化**: 一致キーワードのイエローバッジ (`<mark>`) ハイライト, YAML Front Matter タグ名 (`#タグ`) 検索, ヒット対象ファイル名の高コントラストカラー表示。
- [x] **PDF & 印刷最適化**: プレビュー描画領域からの A4 100%フルサイズ印刷、編集画面/UI要素の `print:hidden` 排除、ダイレクト PDF ワンクリック保存。
- [x] **Rust アクセラレーション**: 10MB+ チャンクストリーミング (`read_file_chunk_native`), 転置インデックス爆速全文検索 (`search_documents_native`), `rayon` 一括文字コード変換, `similar` 行単位 Diff 比較。
- [x] **バージョン管理の単一化**: プログラム内のハードコーディング全廃、`package.json` からの動的バージョン参照。
