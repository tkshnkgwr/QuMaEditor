## 🎯 完了済みタスク (Completed)

### v1.4.0 リリース版 (2026-08-18)

- [x] **エディタ打鍵時の入力遅延解消・プレビュー更新の非同期分離（ゼロレイテンシ化）**: 「編集のみ」モード時のプレビュー完全アンマウント・バイパス、および「分割表示」モード時のプレビュー解析遅延（Debounce / `useDeferredValue`）による高速タイピング追従の実現。
- [x] **`Ctrl+E`（プレビュー復帰時）のカーソル位置・フォーカス自動復元**: プレビュー表示から `Ctrl+E` またはヘッダー操作でエディタへ戻った際、直前のカーソル位置・選択範囲を自動復元しエディタへ即座にフォーカス。
- [x] **Markdown 自動整形（フォーマッター）機能 (`Ctrl+Shift+F`)**: Rust ネイティブで、見出し前後の空行挿入、表組みの垂直整列、連続空行圧縮（コードブロック保護付き）を一括実行する「✨ 整形」ボタン＆ショートカットの実装。
- [x] **保存ステータス（「実ファイルに保存」等）の表示を StatusBar へ集約**: TitleBar（ヘッダー部）の保存状態表示を StatusBar（フッター）へ移動・集約し、UIをすっきり整理。
- [x] **外部プロセス更新検知＆選択時自動最新化・手動再読込 (`F5`)**: 外部エディタでのファイル変更を `mtime` で自動検知しトースト通知・自動更新。手動でのディスク再読込 (`F5` / `Ctrl + R`) も完備。
- [x] **Rust ネイティブ・シンタックスハイライト事前生成 (`syntect`) & HTML 出力**: コードブロックの構文解析・色分けを Rust (`syntect`) で行い、大容量テキストのプレビュー高速化と完全スタンドアロン HTML エクスポートを実現。
- [x] **CSVデータの表形式プレビュー表示（自動アライメント・ソート・検索）**: CSVファイルや記述データのプレビュー時、美しいインタラクティブテーブルとして描画し、型自動判別（文字型は左寄せ、日付は中央、数値型は右寄せ）＆クリックソート・検索フィルターを実装。
- [x] **ドキュメント詳細統計ダッシュボードモーダル (`StatsModal`)**: 文字数、単語数、行数、読了予想時間（分）、見出し数、リンク数をリアルタイム集計・グラフ表示するモーダルの新設（StatusBar クリックで呼び出し可能）。
- [x] **エディタカスタマイズ設定の拡張**: 基本フォントサイズに加え、「行間 (Line Height)」「エディタフォントファミリー (Monospace / Sans-serif)」「タブ幅」の設定項目を追加。
- [x] **単一ファイル 1,000行超過時のモジュール分割リファクタリング**:
  - バックエンド `text_processing/`（`stats.rs`, `yaml.rs`, `structure.rs`, `csv.rs`, `formatter.rs`, `html_renderer.rs`）へ分割。
  - フロントエンド `useGlobalShortcuts.ts`, `ModalGroup.tsx`, `MarkdownRenderers.tsx` へ分割。
  - 全ソースファイルが 1,000 行未満に収まり、責務が綺麗に整理。
- [x] **Markdown プレビューでの Mermaid ダイアグラム リアルタイム描画＆ズーム・最大化拡大表示**: ````mermaid ... ```` 構文ブロックを自動検出し、フローチャート・シーケンス図・状態遷移図等の美しい SVG 図をリアルタイム描画する `MermaidRenderer` を実装。文字がはっきり読めるフォントサイズ最適化、ズームイン/ズームアウト（50%〜600%）、大画面フルスクリーン拡大モーダル、ライト/ダークモード自動連動、コードコピーボタンを完備。
- [x] **大容量CSV・テキストファイルの遅延読み込み（チャンクロード）**: 47,000行（数MB〜数十MB）規模の大容量ファイルを開く際、冒頭 1,500 行（約 150KB）のみを 0.01 秒で瞬時に読み込むオンデマンド・チャンクロードを実装。
- [x] **Rust ネイティブ CSV 高速解析プレビュー (`parse_csv_preview_native`)**: 3MB〜10MB クラスの大容量 CSV を開いた際の表示ラグを解消するため、JavaScript の同期 `split('\n')` パースを廃止し、Rust ネイティブによるゼロコピー高速行カウント・クォート対応セル抽出を実装。
- [x] **大容量CSV・テキストファイル表示の超高速化**: 3MB（数万〜10万行以上）のファイルを開いた際の初期レンダリングフリーズを解消するため、行番号の DOM 生成を 100,000 個 ➔ 1 個の単一 `<pre>` テキストノードへ置換（DOM負荷 99.99% 削減）。
- [x] **CSVファイルのストレージ非保存・自動保存無効化・ReadOnly制御**: CSVデータ（`.csv`）を開いた際は LocalStorage への内部保存を行わず、自動保存タイマーも完全停止。
- [x] **主要処理の Rust ネイティブ移行（全23単体テストパス）**: リアルタイムテキスト統計、YAML Front Matter パース、見出し目次抽出、タスク項目状態トグル、表組み自動整形、HTML エクスポートを Rust 化。
