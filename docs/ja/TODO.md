## 🎯 完了済みタスク (Completed)

### v1.4.0 リリース版 (2026-08-17)

- [x] **Markdown プレビューでの Mermaid ダイアグラム リアルタイム描画＆ズーム・最大化拡大表示**: ````mermaid ... ```` 構文ブロックを自動検出し、フローチャート・シーケンス図・状態遷移図等の美しい SVG 図をリアルタイム描画する `MermaidRenderer` を実装。文字がはっきり読めるフォントサイズ最適化、ズームイン/ズームアウト（50%〜300%）、大画面フルスクリーン拡大モーダル、ライト/ダークモード自動連動、コードコピーボタンを完備。
- [x] **CSV ファイル表示時のステータスバー情報最適化**: CSV ドキュメント表示時は「読了目安」および「単語数」を非表示にし、行数・文字数・カーソル位置・文字コードのみのすっきりとした表示へ最適化。
- [x] **大容量CSV・テキストファイルの遅延読み込み（チャンクロード）**: 47,000行（数MB〜数十MB）規模の大容量ファイルを開く際、全文の一括読み込みをやめ、冒頭 1,500 行（約 150KB）のみを 0.01 秒で瞬時に読み込むオンデマンド・チャンクロードを実装。最下部に「さらに読み込む」「全文を一括読み込み」ボタンを配置し、編集有効化時の自動全文ロードにも完全対応。
- [x] **Rust ネイティブ CSV 高速解析プレビュー (`parse_csv_preview_native`)**: 3MB〜10MB クラスの大容量 CSV を開いた際の表示ラグを解消するため、JavaScript の同期 `split('\n')` パースを廃止し、Rust ネイティブによるゼロコピー高速行カウント・クォート対応セル抽出を実装。Front Matter パースのバイパスと合わせ、プレビュー表示のラグをゼロ化。
- [x] **大容量CSV・テキストファイル表示の超高速化**: 3MB（数万〜10万行以上）のファイルを開いた際の初期レンダリングフリーズを解消するため、行番号の DOM 生成を 100,000 個 ➔ 1 個の単一 `<pre>` テキストノードへ置換（DOM負荷 99.99% 削減）。改行カウントのゼロアロケーション走査、および CSV 専用の軽量サマリーテーブルプレビューを実装。
- [x] **CSVファイルのストレージ非保存・自動保存無効化・ReadOnly制御**: CSVデータ（`.csv`）を開いた際は LocalStorage への内部保存を行わず、自動保存タイマーも完全停止。開いた直後は読み取り専用（ReadOnlyバナー表示）とし、「編集を有効化」ボタンを押した場合のみ手動編集・`Ctrl+S` 手動保存を許可する安全制御を実装。
- [x] **PCファイルの外部更新検知＆自動再読み込み（通知付き）**: 外部エディタや別プロセスでのファイル変更を OS の `mtime`（最終更新日時）ベースで超軽量に検知。ウィンドウフォーカス復帰時および 2.5 秒定期ポーリングで最新状態に自動再読み込みし、「別プロセスから更新されました。再読み込みします。」のトースト通知を表示。
- [x] **主要処理の Rust ネイティブ移行（超高速化・低メモリ化）**: リアルタイムテキスト統計 (`calculate_text_stats_native`)、YAML Front Matter 高速パース (`parse_yaml_front_matter_native`)、見出し目次抽出 (`extract_headings_native`)、タスク項目状態トグル (`toggle_task_native`)、完全 HTML エクスポート (`export_html_full_native`) を Rust 化し、単体テスト 20 件を完備。
- [x] **キーワード検索の UTF-8 文字境界安全化**: 日本語長文での検索スニペット生成時にマルチバイト文字途中で切断され panic する問題を文字数単位の安全なスライスに修正。
- [x] **「編集のみ」モード時の印刷プレビュー描画保持**: `viewMode === 'editor'` 時に印刷してもプレビューが白紙にならず、正常に出力されるよう DOM 構造を保持。
- [x] **`Ctrl+E` キーボードショートカットによる高速表示モード切替**: 「編集のみ」↔「プレビューのみ」を `Ctrl+E` で瞬時にトグル切替（分割表示時は誤操作防止のため無効化）。
- [x] **プレビュー見出し（H1〜H6）カラーテーマ機能**: 設定画面から 4 種類（落ち着いた色、鮮やか、ハイコントラスト、モノトーン）を選択・即時反映。
- [x] **ライトモード時のスクロールバー＆印刷ダイアログのテーマ同期**: `color-scheme` メタタグ・CSS変数および `<html>` タグへの同期により、ライトモード時にスクロールバーや印刷ダイアログがダークモードになる問題を解消。
- [x] **ワンクリック補助ツールバーの完備**: テーブル挿入補助モーダル、コードブロック、引用（`> `）、チェックボックス（`- [ ] `）のワンクリック挿入ボタンを実装完了。
