# Contribution Guidelines (CONTRIBUTING)

## 1. Commit Message Conventions

Please follow standard conventional commit prefixes:

- `feat:` New feature additions
- `fix:` Bug fixes
- `docs:` Documentation updates
- `style:` Formatting changes with no logic impact
- `refactor:` Code refactoring

## 2. Coding Standards

- Comply with TypeScript strict mode settings.
- Keep source code comments clear and concise.
